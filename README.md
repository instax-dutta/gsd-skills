# gsd-skills

GSD (get-shit-done) workflow primitives for coding agents - 16 standalone skills
covering planning, execution, review, debugging, and session management.

## Install

```bash
git clone https://github.com/instax-dutta/gsd-skills.git ~/.config/opencode/skills/
```

Or with the skills CLI:

```bash
npx skills add instax-dutta/gsd-skills
```

## Skills

| Skill | Purpose |
|---|---|
| `gsd-plan-phase` | Plan a development phase |
| `gsd-execute-phase` | Execute an approved phase plan |
| `gsd-ship` | Ship the finished work |
| `gsd-code-review` | Review code before merge |
| `gsd-debug` | Structured debugging sessions |
| `gsd-quick` | Small fixes without ceremony |
| `gsd-fast` | Fast path for well-understood changes |
| `gsd-health` | Check project and workflow health |
| `gsd-progress` | Show current progress |
| `gsd-stats` | Session statistics |
| `gsd-pause-work` | Pause and checkpoint a session |
| `gsd-resume-work` | Resume a paused session |
| `gsd-config` | Configure the workflow |
| `gsd-settings` | Inspect or change settings |
| `gsd-undo` | Undo the last workflow step |
| `gsd-help` | List commands and guidance |
